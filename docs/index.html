The Manager CLI: omarchy-fred-plugin

A dedicated CLI tool to inspect, install, update, and diff plugins across local workstations and official marketplace registries: 

# Check live inventory and marketplace status
omarchy-fred-plugin list --all

# Inspect verified registry data
omarchy-fred-plugin info fred.workspaces

# Fast development loop for local QML iteration
omarchy-fred-plugin dev fred.clock on
# ... edit QML with live Quickshell hot-reload ...
omarchy-fred-plugin dev fred.clock off
