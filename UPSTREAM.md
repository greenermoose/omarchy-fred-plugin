# Upstream sources and field surveys

`tam-plugin` manages the `fred.*` suite and reads the official
[Omarchy Plugin Marketplace](https://github.com/omacom/omarchy-plugin-marketplace)
registry. [Omarchy](https://github.com/omacom/omarchy) is the current shell
and plugin-manager integration reference. The
[Tamlinux ecosystem registry](https://github.com/greenermoose/ecosystem-fred-tamlinux)
tracks carried package patches that may affect this tool.

These are known starting points, not a claim that code was copied. A requested
survey should also inspect manager alternatives, forks, and independent
discovery or lifecycle designs. Put dated findings in [upstream/](upstream/)
and link them here. Record any later copied code, license, and attribution
before adoption.
